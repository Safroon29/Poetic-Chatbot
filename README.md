# Poetic Chatbot

> **Where artificial intelligence meets the art of poetry.**

**Poetic Chatbot** is an AI-powered conversational application designed to generate creative, personalized poetry from natural-language prompts. The project explores how generative AI and natural language processing can be used to transform simple ideas, emotions, and themes into expressive poetic compositions.

## Overview

Poetry is a deeply creative form of human expression. This project combines that creativity with artificial intelligence to create an interactive experience where users can provide a theme, thought, emotion, or idea and receive an original poetic response.

The chatbot is developed and experimented with using **Python and Google Colab**, making it easy to develop, test, and iterate on the underlying AI workflow.

## Key Features

* **AI-Powered Poetry Generation**
  Generates original poems based on user-provided prompts.

* **Natural-Language Interaction**
  Users can communicate with the chatbot using simple conversational inputs.

* **Personalized Responses**
  Poetry can be generated around specific themes, emotions, moods, or ideas.

* **Creative Text Generation**
  Produces structured and expressive poetic content rather than simple predefined responses.

* **Interactive Experimentation**
  The Google Colab environment provides a convenient platform for testing prompts and improving the chatbot.

## How It Works

```text
User Prompt
     ↓
Text Processing
     ↓
AI / Language Model
     ↓
Creative Response Generation
     ↓
Personalized Poem
```

The user provides a prompt describing a theme, emotion, situation, or idea. The system processes the input and generates a poetic response based on the context of the request.

## Example

**Input**

```text
Write a poem about finding hope after a difficult day.
```

**Output**

```text
When daylight fades and shadows stay,
A quiet hope still finds its way.
Through every storm, through every night,
A little dawn awaits the light.
```
